# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly by emailing the maintainers directly instead of using the public issue tracker.

**Please do not open a public GitHub issue for security vulnerabilities.**

When reporting a vulnerability, please include:
- A description of the vulnerability
- Steps to reproduce the issue (if possible)
- Potential impact and severity
- Any suggested remediation

## Security Best Practices

When using this project, please follow these best practices:

- Keep your dependencies up to date
- Review code changes carefully before merging
- Use environment variables for sensitive information (API keys, credentials, etc.)
- Enable security features and checks in your repository settings
- Report suspicious activity or potential security issues promptly

## Supported Versions

We actively maintain and provide security updates for:
- The latest version and previous minor versions

Older versions may not receive security patches. Users are encouraged to upgrade to the latest version.

## Dependencies

This Python project uses third-party dependencies. We recommend:
- Regularly updating dependencies using `pip install --upgrade -r requirements.txt`
- Monitoring security advisories for dependencies
- Using tools like `safety` to check for known vulnerabilities in dependencies

## Contact

For security-related questions or to report vulnerabilities, please contact the project maintainers directly.
